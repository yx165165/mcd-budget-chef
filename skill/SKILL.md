# 麦麦口味推荐官 (MCD Flavor Scout)

按口味找麦当劳餐品，并可选地叠加营养约束与最优优惠。

## 何时使用

用户表达以下任一意图时触发：

- **说不出具体想吃什么，但知道自己偏好**：「想吃点甜的」「要辣的」「想吃酥脆的」
- **以某个餐品为锚点**：「我喜欢巨无霸，有没有类似的」「上次那个挺好吃」
- **想换口味**：「换点不一样的」
- **要控营养**：「减脂期想吃麦当劳」「控制在 700 大卡」
- **要省钱**：「凑个满减」「怎么点最省」
- **懒得选**：「随便给我配一份」

## 前置：接入麦当劳 MCP

本 Skill 的菜单、营养、价格、优惠券、历史订单均来自麦当劳官方 MCP。

1. 前往 https://open.mcd.cn/mcp 登录并申请 MCP Token；
2. 在 WorkBuddy 的【专家·技能·连接器】→【连接器】→ 自定义连接器 → 配置 MCP：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

3. 启用 `mcd-mcp`，确认工具列表中可见 `query-meals`、`list-nutrition-foods`、`order-list` 等工具。

> ⚠️ 若 MCP 未接入或工具不可用，必须**如实告知实时数据不可用**，不得用仓库内的演示数据冒充真实结果。

## 执行步骤

### Step 1 · 判断入口（三种）

| 用户说的话 | 入口 | 参数 |
|---|---|---|
| 「想吃甜的/辣的/酥脆的」 | **文本描述** | `--want "<原话>"` |
| 「我喜欢 X / 和 X 类似的」 | **锚点** | `--like "X"` |
| 「按我的习惯推荐」 | **历史** | `--history <订单文件>` |

历史订单获取方式：调用 MCP `order-list` 取近期的到店/外送订单，把餐品名逐行写入
一个临时文本文件（每行一个名字），再传给 `--history`。

### Step 2 · 拉取实时数据（调用 MCP）

| Tool | 用途 |
|---|---|
| `now-time-info` | 确认时段，决定早餐/正餐菜单 |
| `query-meals` | 门店在售餐品（候选池） |
| `list-nutrition-foods` | 营养数据 |
| `order-list` | 历史订单（仅历史入口） |
| `query-nearby-stores` | 用户只给地址时定位门店 |

### Step 3 · 运行推荐引擎

```bash
# 三个入口任选其一
python src/cli.py recommend --want "<原话>" --top 5
python src/cli.py recommend --like "<餐品名>" --top 5
python src/cli.py recommend --history <订单文件> --top 5
```

需要一路算到营养与优惠时，改用 `plan`：

```bash
python src/cli.py plan --want "<原话>" --budget 35 --kcal 700 --min-protein 25 --json
```

需要一句话点餐时：

```bash
python src/cli.py simple "<原话>"
```

### Step 4 · 券与金额复核（推荐）

用 `query-store-coupons` / `available-coupons` / `query-my-coupons` 取券数据，
用 `calculate-price` 传入最终组合，复核金额与优惠是否与本项目算的一致。
**若不一致，以官方返回为准**，并向用户说明差异。

### Step 5 · 用中文输出

口味推荐（主功能）固定用这个结构：

```
【你的口味画像】偏甜、爱酥脆

【推荐】
  1. 香芋派  匹配度 90%
     风味：甜5 咸1 ｜ 口感：酥脆、绵密
     为什么是它：甜度 5/5 完全对上；「酥脆」命中你的口感偏好
  2. ...
```

完整方案固定用这个结构：

```
【方案】实付 ¥26.50（原价 ¥32.50，用「满30减6」省 ¥6.00）
  组合：麦辣鸡腿汉堡 + 麦辣鸡翅(2块)
  营养：777 kcal | 蛋白 41g | 脂肪 41g | 碳水 59g | 钠 1670mg
  ✅ 热量 ≤ 上限 ｜ ✅ 蛋白质 ≥ 要求
```

### Step 6 · 下单（仅在用户明确确认后）

用户说「就这个，帮我下单」时才调用 `create-order`。下单前必须复述：
门店、就餐方式、餐品清单、实付金额，请用户确认。

## 输出规范

- **必须给出匹配理由**：「甜度对得上」比「符合口味」更有说服力，且可核查；
- **必须说明数据来源**：口味标签是基于公开配料的推断，价格/营养以麦当劳官方实时结果为准；
- **数据缺失时如实说「无」**，不得用 0 或估计值填充；
- 找不到合适餐品时，**明确说明卡在哪个条件**（如「你要求『冰的』同时又指定了『酥脆热食』，无解」），并给出放宽建议；
- 不要一次列超过 5 个推荐，多了用户看不过来。
